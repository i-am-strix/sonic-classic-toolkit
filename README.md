# Sonic Classic Toolkit

Sonic **C**lassic **T**ool**k**it is a lightweight Classic Sonic framework for Unity. There's like a gazillion other Classic Sonic frameworks out in the wild so I don't think I need to explain how this one works, but it mainly tries to mimic the Genesis era gameplay rather than the more modern Mania gameplay, in things such as how collision works (for better or for worse), some of the limits applied on the player and so on.

I don't expect a lot of people to bother with this as it does some things in a rather unorthodox manner compared to other Sonic frameworks (notably using Addressables and FMOD for audio), but who cares lol

## Pre-requisites

To use the framework, you'll need:
- Unity 2023.2.22f1 or newer
- A compatible code editor, such as **Visual Studio 2019** (I use Jetbrains Rider for those curious)
- [FMOD Studio](https://www.fmod.com/download) to modify the audio

### Big thanks to the [Sonic Physics Guide](https://info.sonicretro.org/Sonic_Physics_Guide) for providing the research material used to implement the gameplay in Unity!!! It's a really good resource that I recommend you keep close by if you want to delve deeper into Classic Sonic gameplay
