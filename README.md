# Yet Another 2D Sonic Framework

The title says it all. There's nothing fancy to add it's literally just a 2D Sonic framework for Unity that's built on the Genesis Sonic principles (quirks and all)

I don't expect a lot of people to bother with this as, firstly, it's more of a research project that I might use for future games, but also secondly, it does some things in a rather unorthodox manner compared to other Sonic frameworks (notably using Addressables and FMOD Studio for audio), but who cares lol

## Pre-requisites

To use the framework, you'll need:
- Unity 2023.2.22f1 or newer
- A compatible code editor, such as **Visual Studio 2019** (I use Jetbrains Rider for those curious)
- [FMOD Studio](https://www.fmod.com/download) to modify the audio

### Big thanks to the [Sonic Physics Guide](https://info.sonicretro.org/Sonic_Physics_Guide) for providing the research material used to implement the gameplay in Unity!!! It's a really good resource that I recommend you keep close by if you want to delve deeper into Classic Sonic gameplay for your own endeavours
