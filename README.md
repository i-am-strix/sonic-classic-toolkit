# Sonic Classic Toolkit

Sonic **C**lassic **T**ool**k**it is a lightweight Classic Sonic framework for Unity. There's like a gazillion other Classic Sonic frameworks out in the wild so I don't think I need to explain how this works, but it mainly tries to mimic the Genesis era gameplay rather than the more modern Mania gameplay, in things such as how collision works, some of the limits applied on the player and so on.

## Pre-requisites

To use the framework, you'll need:
- Unity 2019.4.40f1 or newer
- A compatible code editor, such as **Visual Studio 2019**
- [FMOD Studio](https://www.fmod.com/download) to modify the audio
